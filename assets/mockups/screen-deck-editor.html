풀 그리드(위/왼쪽, "브라우징 영역")는 기존 132×184 카드 프레임을 82% 스케일로 그대로 재사용 — 새 카드 비주얼 언어를 만들지 않는다(spec §5.5 요구사항). 매수 배지(n/3)는 카드 우하단에 오버레이. 3/3 도달 시 배지가 타입 컬러로 꽉 차고(.full) 카드 자체가 45% 불투명(기존 .unaffordable 패턴 재사용) + 클릭 무반응. "이 덱" 목록(아래/오른쪽, "구성 결과 영역")은 의도적으로 전혀 다른 실루엣 — 카드 프레임이 아니라 코스트 칩 + 이름 + 매수 + − 버튼으로 된 조밀한 리스트 행. 두 영역이 한 화면에서 "지금 보고 있는 것"과 "지금까지 고른 것"으로 시각적으로 분리되어야 한다는 spec §5.5 요구를 그리드 vs. 리스트라는 서로 다른 레이아웃 문법으로 만족시켰다. 20장 미만이 되면 .deck-counter가 .invalid(crimson)로 바뀌고 그 아래 "최소 20장이 필요합니다" 문구가 노출된다(아래 상태 예시 참고).
