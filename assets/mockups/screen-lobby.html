상단 "+ 방 만들기"는 목록 상태와 무관하게 항상 노출(spec §6.2.1) — 목록 유무에 좌우되는 조건부 버튼이 아니다. 행 자체가 참가 액션이라(클릭 = 즉시 참가 시도, 확인 버튼 없음) 화살표 아이콘은 기본 상태에서 숨겨두고 hover/focus에서만 살짝 밀려 나오며 gold로 바뀐다 — "클릭 가능한 행"이라는 신호를 hover 의도가 있을 때만 드러내고, 평상시 목록은 8.7 전적 화면의 조용한 리스트 느낌을 그대로 유지한다. 동명 호스트 두 번째 "야공이" 행은 spec §6.2.2가 다룬 표시 이름 중복 케이스 — 정렬(최신순)과 대기 시간만으로 이미 행끼리 구별되므로 별도 식별자를 붙이지 않는다.
