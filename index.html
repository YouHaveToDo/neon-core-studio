ARCANE LEDGER

ARCANE LEDGER

오컬트 장부 던전 덱빌더 — 버티컬 슬라이스

How to Play

카드로 적을 물리치며 폐허의 심판관까지 도달하라.

턴 진행

  1. 1카드 5장을 뽑는다
  2. 2마나 안에서 카드를 낸다
  3. 3"End Turn"을 누른다
  4. 4적이 예고된 행동을 실행한다

카드 읽는 법

← 좌상단 숫자 = 마나 비용
← 상단 색 바 = 종류 (Attack/Skill/Power)
← 하단 텍스트 = 효과

의도(Intent) 아이콘

적 위의 배지는 적의 다음 행동을 미리 알려준다 — 검 아이콘+숫자 = 이만큼 공격, 방패 아이콘+숫자 = 이만큼 방어. 미리 보고 대응을 준비하라.

방어도(Block)

방패 아이콘 옆 숫자는 이번에 받는 피해를 그만큼 막아준다. 내 다음 턴이 시작되기 전에 사라진다.

카드 내는 법

카드를 탭하면 선택된다. 공격 카드는 이어서 적을 탭해서 조준한다. 스킬/파워 카드는 탭하는 즉시 발동된다.

Deck 0
Discard 0
Hand 0
Mana
Deck 0
Discard 0

승리

폐허의 심판관을 물리치고 던전을 정복했다.

패배

장부가 여기서 닫혔다.
