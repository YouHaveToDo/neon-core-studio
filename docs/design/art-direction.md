# ARCANE LEDGER — 아트 디렉션

기획안(`gdd-arcane-ledger.md`) 섹션 9의 비주얼 스타일을 프로그래머가 그대로 구현할 수 있는 정확한 수치/에셋으로 확정한다.

## 1. 컬러 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#150f1a` | 배경 (짙은 자두빛 잉크) |
| `--bg-raised` | `#1e1624` | 카드/패널 배경 |
| `--bg-inset` | `#120c17` | 오목한 영역 (덱/버림더미 카운터 등) |
| `--line` | `rgba(242,233,216,0.14)` | 테두리/구분선 |
| `--ink` | `#f2e9d8` | 본문 텍스트, 카드 프레임 |
| `--ink-dim` | `#b8a99a` | 보조 텍스트 (카드 효과 설명) |
| `--ink-faint` | `#6f6258` | 레이블/캡션 |
| `--crimson` | `#c23b4c` | Attack 카드, 공격 의도 |
| `--steel` | `#3f8fa6` | Skill 카드, 방어 의도 |
| `--gold` | `#d4af37` | Power 카드, 보스/강조 |

## 2. 타이포그래피

- 카드명·섹션 타이틀: 세리프 — `Georgia, "Iowan Old Style", "Palatino Linotype", "Noto Serif KR", serif`
- 본문/UI 텍스트: 시스템 산세리프 — `-apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`
- 숫자(HP/마나/데미지): 모노스페이스, `font-variant-numeric: tabular-nums`

## 3. 카드 스펙

- 크기: **132×184px** (비율 약 0.72, 표준 카드 비율)
- 모서리 반경: **8px**
- 테두리: 1px, `--line`
- 상단 타입 컬러 바: 높이 **4px** (Attack=crimson / Skill=steel / Power=gold)
- 코스트 배지: 지름 **22px** 원, 카드 좌상단에 절반 걸치도록 배치, 배경은 타입 컬러, 텍스트는 `--bg`
- 내부 패딩: 10px
- 카드명: 13px 세리프 bold
- 효과 텍스트: 11.5px 산세리프, `--ink-dim`, 하단 정렬

## 4. 아이콘 세트

`assets/icons.svg`에 스프라이트 시트로 저장 (24×24 viewBox, stroke 기반, `currentColor` 상속 — 사용처 색상에 맞게 자동 채색됨). 사용: `<use href="assets/icons.svg#icon-sword" />`

| 아이콘 | ID | 용도 |
|---|---|---|
| 검 | `icon-sword` | 공격 의도, Attack 타입 표시 |
| 방패 | `icon-shield` | 방어 의도/방어도, Skill 타입 표시 |
| 왕관 | `icon-crown` | 보스 표시, Power 타입 표시 |
| 마나 방울 | `icon-mana` | 마나 게이지 |
| 해골 | `icon-skull` | 처치/즉사 위협 경고 (선택적 사용) |
| 하트 | `icon-heart` | 플레이어 HP |

일러스트 없이 기하학적 심볼로만 구성 — 팀 아트 제약(SVG/프로시저럴)을 그대로 반영.

## 5. 적 포트레이트 (기하학적 실루엣)

캐릭터 일러스트 대신 도형으로 성격을 암시한다.

| 적 | 도형 | 근거 |
|---|---|---|
| 녹슨 파수병 | 정육각형 | 튼튼하고 정직한 방어형 인상 |
| 그림자 도적 | 회전된 다이아몬드(45°) | 날카롭고 빠른 인상 |
| 폐허의 심판관 (보스) | 대형 정육각형 + 상단 왕관 아이콘 오버레이 | 위압감 + 보스 식별성 |

포트레이트 크기: 96×96px (보스는 120×120px), 채우기는 `--bg-raised`, 테두리 2px `--crimson`(일반) / `--gold`(보스).

## 6. 배틀 화면 레이아웃

- **적 영역** (상단 중앙): 포트레이트 → HP 바 → 의도 배지(아이콘+예상 수치, 포트레이트 위에 말풍선처럼 배치)
- **플레이어 정보** (좌하단): 하트 아이콘+HP, 방패 아이콘+방어도(0이면 숨김)
- **마나 게이지** (플레이어 정보 옆): 마나 방울 아이콘 3개, 소모분은 outline만 남기고 채움 해제
- **손패** (하단 중앙): 카드 최대 5장, 살짝 부채꼴 또는 균등 간격 가로 배열
- **덱/버림더미 카운터** (우하단): 작은 숫자 배지 2개

실제 목업은 아래 링크 참고 — 이 문서의 수치를 그대로 시각화한 것.
