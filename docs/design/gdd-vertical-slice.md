# NEON CORE (가제) — 버티컬 슬라이스 기획안

> **상태: 보류 (2026-07-31)** — 컨셉 후보 2안(로그라이크 덱빌더)으로 첫 프로젝트 방향을 전환. 이 문서는 삭제하지 않고 보관, 추후 다음 프로젝트 후보로 재검토 가능. 현재 진행 중인 기획은 `gdd-arcane-ledger.md` 참고.

## 1. 컨셉

탑다운 서바이벌 아레나. 플레이어는 중앙 코어를 지키며 사방에서 몰려오는 기하학적 적을 자동 공격으로 갈아내고, 시간이 지날수록 기하급수적으로 강해지는 웨이브 속에서 5분간 생존한다.

- **장르:** 서바이벌 아레나 (Vampire Survivors류) + 네온 벡터 비주얼 (Geometry Wars류)
- **레퍼런스를 쓰는 이유:** 재미의 원천이 그래픽 디테일이 아니라 "숫자가 커지는 손맛"과 "화면 가득한 이펙트"에 있어, SVG/프로시저럴 도형만으로도 완성도 있는 룩을 낼 수 있다. Geometry Wars는 단순 벡터 도형 + 발광 이펙트만으로 상용 퀄리티를 낸 실제 전례.
- **플랫폼:** 브라우저 (HTML5 Canvas)
- **세션 길이:** 1회 5분 (버티컬 슬라이스 기준)

## 2. 코어 루프

```
이동으로 위치 선정 → 무기가 자동으로 공격 → 적 처치 시 XP 오브 드롭
→ XP 흡수 → 레벨업 시 3개 중 1개 업그레이드 선택 → 적 밀도/강도 상승
→ (반복, 난이도가 플레이어 성장 속도를 서서히 추월)
```

재미의 핵심: 플레이어는 "회피"만 직접 조작하고 "공격"은 자동이다. 몰입은 점점 화면을 뒤덮는 적과, 그걸 갈아내는 이펙트의 스펙터클에서 나온다.

## 3. 조작

- 이동: WASD / 방향키 (8방향, 아날로그 아님 — 즉시 방향 전환)
- 공격: 자동 (조작 불필요)
- 레벨업 선택: 마우스 클릭 또는 1/2/3 키

## 4. 플레이어

| 항목 | 초기값 |
|---|---|
| HP | 100 |
| 이동속도 | 220 px/s |
| 피격 판정 반경 | 12px |
| 무적 프레임 | 피격 후 0.5초 |

HP 0 → 즉시 게임오버 (부활 없음, 버티컬 슬라이스 범위 밖).

## 5. 무기 (버티컬 슬라이스: 2종, 시작 시 1종 고정 장착)

### 5.1 펄스 블래스트 (시작 무기)
- 가장 가까운 적에게 자동 발사, 사거리 300px
- 데미지 10, 발사 간격 0.6초 (레벨업으로 간격 감소·데미지 증가)
- 관통 없음 (레벨 3 업그레이드에서 관통 1 획득)

### 5.2 체인 라이트닝 (레벨업 드롭으로 획득 가능)
- 랜덤 적 1명 타격 후 반경 150px 내 최대 2명까지 연쇄
- 데미지 6 (연쇄마다 20% 감소), 발사 간격 1.2초

무기당 업그레이드는 3레벨까지 (Lv1 획득 → Lv2 강화 → Lv3 강화). 버티컬 슬라이스는 무기 2종 × 3레벨로 제한 — 시너지 시스템은 다음 버전 스코프.

## 6. 적 (3종 고정, 추가 종 없음)

| 이름 | 행동 | HP | 이동속도 | 접촉 데미지 | 비고 |
|---|---|---|---|---|---|
| 드리프터 | 플레이어를 향해 직선 추적 | 20 | 90 px/s | 8 | 기본 적, 등장 비중 가장 높음 |
| 러셔 | 직선 추적, 드리프터의 2배 속도 | 15 | 180 px/s | 6 | 빠르게 압박, 개별 위협도는 낮음 |
| 스플리터 | 드리프터와 동일 이동, 사망 시 소형 개체 2마리로 분열 (HP 8, 데미지 4)씩 | 30 | 90 px/s | 8 | 화면 밀도를 급격히 높이는 역할 |

적 이동은 단순 추적 AI만 사용 (경로탐색 없음 — 장애물 없는 열린 아레나이므로 불필요).

## 7. 웨이브 / 난이도 커브 (5분 세션)

| 시간 | 스폰 구성 | 스폰 간격 |
|---|---|---|
| 0:00–1:00 | 드리프터만 | 1.2초 |
| 1:00–2:00 | 드리프터 + 러셔 등장 (30%) | 1.0초 |
| 2:00–3:00 | + 스플리터 등장 (20%) | 0.8초 |
| 3:00–4:00 | 스폰 간격 단축, 비율 균등화 | 0.6초 |
| 4:00–5:00 | 최대 밀도, 동시 스폰 2마리 | 0.5초 |
| 5:00 | 생존 성공 — "CORE STABILIZED" 승리 화면 | — |

보스는 버티컬 슬라이스 범위 밖 (5분 생존만으로 승리 처리).

## 8. 레벨업 / 업그레이드

- XP 오브: 적 처치 시 드롭, 자동 흡수 반경 40px (레벨업마다 반경 소폭 증가는 스코프 밖)
- 레벨업 임계값: 5, 12, 22, 35, 52, 75, ... (선형이 아닌 점증 — 후반 렙업 속도가 난이도 상승을 못 따라가도록 의도적으로 설계)
- 레벨업 시 3개 중 1개 선택 (매 레벨 동일 목록에서 랜덤 3개 제시):
  1. 펄스 블래스트 강화 (데미지 or 연사속도, 3레벨까지)
  2. 체인 라이트닝 획득/강화 (미보유 시 획득이 항상 후보에 포함)
  3. 이동속도 +10%
  4. 최대 HP +20 (즉시 전량 회복 아님, 최대치만 증가)
  5. XP 흡수 반경 +15px

## 9. 비주얼 스타일

- 배경: 거의 순수 블랙 (#0a0a12), 그리드 라인 은은하게 (opacity 낮은 네온 시안)
- 플레이어: 흰색~시안 발광 삼각형 (진행 방향 표시)
- 드리프터: 마젠타 다이아몬드
- 러셔: 옐로우 삼각형 (뾰족함으로 "빠름" 암시)
- 스플리터: 오렌지 육각형, 분열 시 절반 크기 육각형 2개
- 이펙트: 피격 시 화면 미세 흔들림(2~4px), 처치 시 파티클 8~12개 확산, 발광(glow)은 CSS/canvas shadowBlur로 처리
- UI: HP바·XP바는 화면 하단 얇은 네온 바, 숫자 폰트는 모노스페이스로 "시스템" 느낌

## 10. 명시적 스코프 제외 (다음 버전으로)

- 무기 시너지/조합 시스템
- 보스전
- 유물/영구 성장(메타 프로그레션)
- 사운드/BGM (있으면 좋지만 버티컬 슬라이스 필수 아님 — 프로그래머 재량으로 간단한 절차적 비프음 정도만 스트레치 목표)
- 난이도 옵션, 세이브/로드
- 5분 이후 진행 (무한 모드 등)

## 11. 완료 기준 (버티컬 슬라이스 Definition of Done)

- 플레이어 이동/피격, 무기 2종, 적 3종, 5분 웨이브 커브, 레벨업 5개 업그레이드가 모두 동작
- 5분 생존 시 승리 화면, HP 0 시 패배 화면이 뜬다
- 60fps 근처로 적 40~50마리 동시 처리 가능 (프레임 드랍으로 "허접함" 체감되지 않을 것)
