# ARCANE LEDGER — 온보딩 (규칙 설명)

첫 플레이 빌드가 "어떻게 하는지 전혀 모르겠다"는 피드백을 받았다. 게임 로직은 스펙대로 맞지만 규칙을 설명하는 화면이 아예 없었던 것이 원인 — GDD에 명시적으로 스코프 제외한 적도 없이 그냥 누락됐다. 이 문서로 최소 온보딩을 확정한다.

## 1. 원칙

- 카드 게임을 처음 접하는 사람도 "규칙 설명 화면 하나"만 읽으면 첫 전투를 스스로 진행할 수 있어야 한다.
- 텍스트로 다 설명하려 하지 않는다 — 화면에 이미 보이는 요소(마나 방울, 카드, 의도 배지)를 그림/아이콘과 함께 짧게 설명한다.
- 강제로 여러 페이지 넘기게 하지 않는다. 한 화면에 전부 담고, 원할 때 다시 볼 수 있게 한다.

## 2. "How to Play" 화면

**노출 시점**: "Begin Run" 클릭 직후, 첫 전투 진입 전에 1회 자동 표시. 이후에는 배틀 화면 상단의 `?` 버튼으로 언제든 다시 열람 가능.

**구성** (한 화면, 스크롤 가능):

1. **목표**: "카드로 적을 물리치며 폐허의 심판관까지 도달하라."
2. **턴 진행 4단계** (아이콘+한 줄씩, 순서대로):
   - 카드 5장을 뽑는다
   - 마나(💧 아이콘) 안에서 카드를 낸다
   - "End Turn"을 누른다
   - 적이 예고된 행동을 실행한다
3. **카드 읽는 법**: 카드 실제 예시 1장을 시각적으로 보여주며 라벨링 — 좌상단 숫자 = 마나 비용, 상단 색 바 = 종류(빨강 Attack / 파랑 Skill / 금 Power), 하단 텍스트 = 효과.
4. **의도(Intent) 아이콘**: "적 위의 배지는 적의 *다음* 행동을 미리 알려준다 — 검 아이콘+숫자 = 이만큼 공격, 방패 아이콘+숫자 = 이만큼 방어. 미리 보고 대응을 준비하라."
5. **방어도(Block)**: "방패 아이콘 옆 숫자는 이번에 받는 피해를 그만큼 막아준다. 내 다음 턴이 시작되기 전에 사라진다."
6. **카드 내는 법**: "카드를 탭하면 선택된다. 공격 카드는 이어서 적을 탭해서 조준한다. 스킬/파워 카드는 탭하는 즉시 발동된다."

닫기 버튼 텍스트: "시작하기" (첫 노출 시) / "닫기" (`?`로 재열람 시).

## 3. 상시 라벨 보강

설명 화면과 별개로, 배틀 화면 자체에도 처음 보는 사람이 헷갈리지 않도록 작은 캡션을 추가한다:

- 마나 게이지 위/옆에 "MANA" 라벨 (기존엔 아이콘만 있고 텍스트 라벨이 없었음)
- 배틀 화면 상단바에 `?` 버튼 추가 (규칙 화면 재열람용, 우측 상단 고정)

## 4. 스코프

- 가이드형 첫 턴 튜토리얼(화면 위 요소를 하나씩 하이라이트하며 강제로 따라하게 하는 방식)은 이번 버전 범위 밖 — 스코프 초과. 위 "규칙 설명 화면 1장 + 상시 라벨"로 충분한지 다음 리뷰에서 재확인한다.
- 사운드/음성 튜토리얼 없음.
